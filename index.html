Setup / 設定

  1. Admin → Chatbot Management → Domain Setting: register 20206205tech.github.io with type Normal.
  2. Put the downloaded mrag-verify-*.txt at the root of the 20206205Tech.github.io repo, push, wait for the Pages deploy, then click Verify.
  3. Widget list → Embed code: copy the <script> into the WIDGET EMBED block, push again.
